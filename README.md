# Omicrux

Marketing website for Omicrux, a PR & branding agency. Built with React, Vite and React Router, deployed on Netlify.

## Getting started

```bash
npm install
npm run dev        # start the dev server at http://localhost:5173
npm run build      # production build into dist/ (pre-renders every page)
npm run preview    # serve the production build locally
npm run lint
```

## Project structure

```
src/
  main.jsx          browser entry: hydrates the pre-rendered page
  routes.jsx        route table (pages other than Home are lazy-loaded)
  entry-server.jsx  build-time renderer used by scripts/prerender.mjs
  seo/meta.js       page titles, descriptions, social tags, structured data
  layout/           MainLayout: Navbar + page + Footer
  pages/            one file per route
  components/       page sections, each with its own .css file
  data/             shared data (social links, blog posts)
public/
  images/           optimized WebP images (generated, see below)
raw-images/         full-size originals (not deployed)
scripts/            build helpers
```

## Images

Add original images to `raw-images/`, register them in `scripts/optimize-images.mjs`, then run:

```bash
npm run optimize-images
```

This writes compressed WebP files to `public/images/`. Reference those from the code, never the originals.

## Deployment

`netlify.toml` configures the build, the 404 page, caching and security headers.
The contact form uses Netlify Forms. Submissions appear under **Forms** in the Netlify dashboard. The form only submits successfully on Netlify, not in local dev.

## Styling

Global design tokens live in `src/index.css` (`:root`): fonts, a fluid type scale (`--fs-*`), colours and spacing (`--gutter`). Use these variables in component CSS instead of hard-coded values.

Fonts (Poppins and League Spartan) are self-hosted through `@fontsource`, so there are no requests to Google Fonts.

## SEO

`npm run build` builds the site, then `scripts/prerender.mjs` renders every page to static HTML (`dist/about.html`, `dist/blog/<slug>.html`, ...). Each page gets its own title, description, canonical URL, Open Graph/Twitter tags and JSON-LD structured data. The script also writes `404.html`, `sitemap.xml`, `robots.txt` and `_redirects`.

- **Titles and descriptions:** edit them in `src/seo/meta.js`. Blog posts take theirs from `src/data/posts.js`, and new posts are added to the sitemap automatically.
- **Site URL:** canonical links and the sitemap use Netlify's `URL` (the site's primary domain). Set `VITE_SITE_URL` to override it. The fallback is `https://omicrux.netlify.app`.
- **Social profiles:** once `src/data/socials.js` has real profile URLs, they are added to the Organization structured data (`sameAs`) automatically.
- **Share images and icons:** `public/og/` and `public/icons/`, generated by `npm run optimize-images`.
